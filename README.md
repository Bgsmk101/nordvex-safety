# NORDVEX

Многостраничный сайт производителя профессиональной спецодежды и СИЗ.

## Стек

- Next.js
- React
- TypeScript
- статический экспорт для GitHub Pages

## Локальный запуск

```bash
npm ci
npm run dev
```

## Сборка

```bash
npm run build
```

Изображения в демонстрационной версии загружаются с Pexels и используются по лицензии Pexels.
