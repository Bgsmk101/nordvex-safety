# NORDVEX

Многостраничный сайт производителя профессиональной спецодежды и СИЗ.

**Демо:** [bgsmk101.github.io/nordvex-safety](https://bgsmk101.github.io/nordvex-safety/)

## Страницы

- Главная — позиционирование, продуктовая архитектура и доказательства качества
- Каталог — шесть систем защиты с фильтрацией
- Отрасли — матрица рабочих сценариев и рисков
- Производство — протокол разработки и контроль качества
- Компания — манифест, принципы и история
- Контакты — интерактивный демонстрационный бриф

## Стек

- Next.js
- React
- TypeScript
- статический экспорт для GitHub Pages
- адаптивная вёрстка от 320 px до широких экранов
- локальные оптимизированные изображения без внешних фотохостингов

## Локальный запуск

```bash
npm ci
npm run dev
```

## Сборка

```bash
npm run build
```

Сайт является демонстрационным проектом для портфолио. Фотографии созданы специально для проекта, а продуктовые схемы хранятся локально в SVG.
